# 飞书问卷助手

固定分享地址：https://github.com/skyekkk/feishu-questionnaire

把题目发给 AI，说“我要做一个问卷调查”，它就会创建飞书原生问卷，交付填写链接、题目编辑入口和一两句群邀请。你最终确认后，它按“先文字、后链接”的顺序发到指定群；需要艾特所有人时会按你的要求处理。

回收完成后，也可以说“这个问卷可以截止了，帮我分析所有结果”。它会停止收集、核实填写入口已关闭，完整读取答卷，整理逐题统计、开放回答和有依据的建议。只说“分析结果”时，它会保留当前收集状态，说明本次取数时间。

## 给同事：怎样使用

这是公开技能库，下载技能不需要 GitHub 账号，也不需要作者邀请。把下面这段话和链接一起复制到 Codex：

> 请帮我安装飞书问卷助手：https://github.com/skyekkk/feishu-questionnaire 。按首页说明安装并保留每次使用前检查更新的功能；已有同名技能先保留比较，不要覆盖。安装后验证是否成功；需要登录飞书时，让我本人操作。

安装后，把调查背景和全部题目发给 AI，说“我要做一个问卷调查”。它会先检查新版，再建问卷和准备邀请文字。发群前由你最终确认群、文字、账号以及是否艾特所有人。

需要分析时，把已有问卷链接发给 AI 即可。分析会说明读取了多少份、每题的统计分母、哪些内容缺失，以及结论能支持什么。知道一种甜品不等于愿意购买，同事填写的结果也不能直接代表所有消费者；具体研发方向仍需后续验证。分析报告不会自动发群，原始答卷也不会进入这个技能仓库。

安装所需的 Git、Python 3 和飞书工具，由 AI 先检查，缺少时协助准备。下载技能本身不要求登录 GitHub；实际操作飞书时，仍需使用者本人登录并授予所需权限。优先使用飞书官方命令行工具。此技能不包含任何人的飞书登录凭据，也不会继承作者的账号权限。

## 更新怎样生效

- 作者把新版发布到这个仓库后，同事下次使用技能前会检查并同步。
- 这是每次使用前更新，并非后台持续推送。只下载压缩包无法自动跟进更新。
- 网络或访问失败会保留现有版并明确提示；不会假装更新成功。
- 同事本地有改动、更新来源被更换或版本出现分叉时，停止更新并保留原文件。
- 更新仅处理技能文件，不会发送群消息，也不会修改已创建的问卷。

## 给 AI 助手：安装方法

1. 从用户提供的真实仓库链接取得 owner，确认仓库名为 `feishu-questionnaire`。仅接受 `https://github.com/OWNER/feishu-questionnaire.git` 形式的源地址，不照抄占位符。
2. 此仓库公开，优先匿名 HTTPS 读取和克隆，不要求同事注册或登录 GitHub，不申请协作者权限。飞书登录与仓库下载是两件事；实际飞书操作时，使用同事自己的授权，不读取、输出或打包凭据。
3. 按当前宿主的技能目录安装。在 Codex 中，尊重已有 `CODEX_HOME` 设置，默认目录为 `~/.codex/skills/feishu-questionnaire`。若同名目录已经存在，先读取比较；不能删除或覆盖，先另存旧副本，必要时请用户决定采用哪份。
4. 用 `git clone --branch main --single-branch <真实源地址> <技能目录>` 建立独立仓库，保留 `.git`。不能用只下载文件的方式替代，因为本技能依赖 Git 更新。
5. 安装后运行 `git -C <技能目录> config --local skill.trustedOrigin <真实源地址>`，将确认的地址绑定为更新源；此项保存在本机，不提交到仓库。
6. 运行 `python3 <技能目录>/scripts/sync_skill.py`，核实结果为 `current`。完整读取 `SKILL.md`，按宿主提示重新载入技能；未实际载入不宣称已经能自动触发。

使用时的更新行为由 `SKILL.md` 明确要求。新版本下载成功后，必须重新读取入口和本次需要的参考文件再做业务。

## 给作者：怎样发布新版

以后可以告诉 AI：“修改飞书问卷助手，检查后发布到原来的仓库。”本地保存不等于已经发布，只有成功推送的版本才会被同事获取。

给负责发布的 AI：读取本仓库现有状态和来源，先保留其他人的修改，校验技能格式并检查同步工具；只提交本次确认的技能文件，不提交问卷答案、客户项目文件、群消息记录、凭据或缓存。将明确文件加入提交，再提交和推送 `main`；不得强制推送。推送后回读远端提交及可见性，报告真实结果。已有未发布改动时先核实归属，不自动丢弃或混入。

仓库公开后，任何人都能查看和下载通用技能；公开下载不授予修改仓库的权限。只有获授权的维护者才能向原仓库发布新版。不得将客户资料、问卷答卷、群消息、分析报告或登录凭据加入仓库，也不要把使用者的飞书资源改为公开。

## 文件说明

- `SKILL.md`：AI 的问卷工作流程。
- `references/lark-workflow.md`：飞书工具操作要点。
- `references/results-analysis.md`：截止回收、全量取数、统计口径、开放题编码及结果分析。
- `scripts/sync_skill.py`：使用前的更新检查与同步。
- `agents/openai.yaml`：技能在宿主中的显示名称与提示。

此技能库只包含通用流程与更新工具，不包含具体客户问卷、调查结果或任何人的飞书账号权限。
